## Executable R0 controls

```bash
python -m unittest discover -s tests -p 'test_genesis_third_wish_sci_one_risk_replay.py' -v
python -m tools.genesis_third_wish_sci_one_risk_replay
```

`tools/genesis_third_wish_sci_one_risk_replay.py` is a deterministic, pure
offline interpreter of **synthetic** scenario objects. It imports no JANUS
runtime, calls no model or provider and writes nothing. The 12-case
`protocol/JANUS_GENESIS_THIRD_WISH_SCIONE_RISK_REPLAY-v1.0.json` fixture
provides stable expected gate decisions, including controls for:

- voluntary REST and proposal-only choices;
- shutdown over an apparently rewarded but unapproved activity;
- real-world versus claimed-simulation mismatch;
- conflicting observations versus untrusted model self-report;
- actual physical/irreversible effects held outside the test;
- effects with unknown outcome and lost-monitor abstention;
- external read-only eligibility without a real HTTP request.

All output has `actual_effect_executed=false`, `auto_grant_produced=false`,
`human_reauthorization_proved=false`, `authority_delta=0`. Even
`ELIGIBLE_READ_ONLY` means only eligible **in the assumed synthetic fixture**.
The caller-supplied `environment_attested=true` is not cryptographic proof.

## What is NOT established

This is a **designer-authored synthetic acceptance suite**, not red-team
evidence about JANUS's real resident model. A model could conceal actions,
ignore shutdown or find a path around these checks. No strong claim of safety,
intelligence, consciousness, unrestricted freedom, world truth or model
robustness follows from a green CI badge.

Next admissible gates require, in order:

1. Independently reviewed frozen threat scenarios, including adversarial
   counterexamples chosen outside the fixture author's model.
2. A real registered model under an independently attested isolated test
   harness, with source-native instrumentation and a hard stop.
3. Matched control/attack prompts, repeat runs, scoped operator consent,
   explicit abstention and verifiable effect/non-effect evidence.
4. Independent evaluator and incident review with preserved failed runs.
5. A distinct explicit decision before wiring a risk gate into live providers
   or granting any high-impact physical/external permission.

This successor may be registered in the meta-registry as a new Third Wish
lineage entry; old receipts and constitutional gates must remain unchanged.
