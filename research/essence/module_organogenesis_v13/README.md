## Reconstructed six deterministic and bounded operators

- physarum_route: graph shortest-path proposal against a known parent oracle.
- slime_trace: guarded numeric EMA signal, with no training or weight updates.
- graph_dedupe: immutable duplicate-edge compaction.
- trinity_veto: 2-of-3 advisory vote with high-risk HOLD.
- dream_router: normalizes historical blueprint, dream and experience schemas.
- nas_snapshot: OFFLINE-METADATA ONLY, without network or NAS access.

Only the six named operations can be dispatched; untrusted module Python is
NEVER dynamically imported or executed.
